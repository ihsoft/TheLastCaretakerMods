# Analysis artifacts

This directory stores reproducible outputs from the installed game:

- `mappings/` — UE4SS `.usmap` or `.jmap` reflection mappings;
- `blueprints/` — JSON and decompiled Kismet for relevant assets;
- `reports/` — compact, human-readable findings and dependency graphs;
- `raw/` and `extracted/` — large intermediate data (ignored by Git).
