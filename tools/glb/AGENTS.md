# GLB support tools index

This directory contains source-only GLB inspection, preview, validation, and
Blender conversion helpers. Choose the operation in [GLB tools](../glb-tools.md)
and invoke the documented script directly.

The inspectors never execute `extras`; preview and conversion require Blender,
while structural inspection uses Python. Outputs are derived evidence and must
not replace their source GLB merely to inspect it.
