# PearFix

Automatically repairs existing pears whose missing tree registration blocks
harvesting and growth, on save loading and streamed arrival. Shows a brief
`Pears fixed: N` message when fruit is repaired. Requires DML.

Build a candidate with:

```powershell
python -B tools/run_powershell.py mods/PearFix/Build-PearFix.ps1 -AllowDirtySource
```

See [build operations](BUILD.md) for installation and validation.
