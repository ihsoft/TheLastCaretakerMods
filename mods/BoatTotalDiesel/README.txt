BoatTotalDiesel
===============

Shows total Diesel from all modules in the same Boat grid in the lower-right
vehicle HUD. Petrol is a separate resource and is not included.

Installation
------------

Copy BoatTotalDiesel_P.pak, BoatTotalDiesel_P.ucas, and
BoatTotalDiesel_P.utoc into:

<Game>\Voyage\Content\Paks\

All three files belong to one container and must be installed or removed
together. The mod requires neither UE4SS nor DML.
