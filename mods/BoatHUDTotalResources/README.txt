BoatHUDTotalResources
===============

Shows total Diesel and Electricity from all modules in the same Boat grid in
the lower-right vehicle HUD. Petrol is a separate resource and is not included.

Installation
------------

Copy BoatHUDTotalResources_P.pak, BoatHUDTotalResources_P.ucas, and
BoatHUDTotalResources_P.utoc into:

<Game>\Voyage\Content\Paks\

All three files belong to one container and must be installed or removed
together. The mod requires neither UE4SS nor DML.
