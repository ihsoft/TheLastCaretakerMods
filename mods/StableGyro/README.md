# StableGyro

Stabilizes Gyro flight, adds four configurable mooring ports, a camera compass
and a player-centered minimap. Open the interactive map with the third action
(V by default); Inspect (G by default) toggles the minimap.

```powershell
python -B tools/run_powershell.py mods/StableGyro/Build-StableGyro.ps1
```
