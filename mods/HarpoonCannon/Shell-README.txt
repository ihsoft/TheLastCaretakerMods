HarpoonCannon shell-return experiment (Steam build 25056839)

Replaces the Cyclone construction actor with the accepted rough cannon model.
No Drone, operator entry, diagnostic HUD, zoom, aiming or firing is included.
Use a disposable test save. No cannon is required in the save before loading.

Test in order:
1. Load the save; open Cyclone construction preview.
2. Place an unfinished cannon and cancel it with Q.
3. Build another cannon; check the complete model stays visible.
4. Check its attachment while the ship moves and rocks; dismantle it.
Report any crash or unwanted motion immediately. Do not save a failed test.

This is a current-engine reconstruction of a historically tested shell, not
a gameplay-validated release. The package intentionally contains exactly the
Cyclone leaf actor and three mod-authored meshes. No stock parent override or
native game binary is shipped. After the test, close the game for manifest-
guarded removal before normal play. Removal does not repair a test save.
