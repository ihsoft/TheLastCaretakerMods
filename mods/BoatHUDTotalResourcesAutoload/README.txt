BoatHUDTotalResources
===============

Shows total Diesel and Electricity from all modules in the same Boat grid in
the lower-right vehicle HUD. Petrol is a separate resource and is not included.

Installation
------------

Copy BoatHUDTotalResources.pak, BoatHUDTotalResources.ucas,
BoatHUDTotalResources.utoc, and BoatHUDTotalResources.autoload into:

<Game>\Voyage\Content\Paks\

All four files belong to one mod and must be installed or removed together.
The entry actor uses the DML-compatible identity
/Game/Mods/BoatHUDTotalResources/ModActor.ModActor_C.
